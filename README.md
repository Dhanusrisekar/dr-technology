# D&R Technologies Website

Responsive static website built with HTML, CSS and vanilla JavaScript.

## Pages
- `index.html` — Home
- `about.html` — About Us
- `services.html` — Services
- `portfolio.html` — Founder's Technical Portfolio (academic/research projects clearly labelled)
- `contact.html` — Contact Us

## Run locally
Extract the ZIP and open `index.html` in a browser. You can also open the folder in VS Code and use the Live Server extension.

## Add your phone number later
In `contact.html`, replace `[9344247264]` with your phone number. Replace the footer placeholder `Phone: 9344247264` in each HTML file too.

## Free hosting with GitHub Pages
1. Sign in to https://github.com/ or create a free account.
2. Create a new **public** repository, e.g. `dr-technologies-website`.
3. Extract this ZIP. Upload the files and folders inside the extracted folder to the repository root. `index.html` must be at the root, not inside another nested folder.
4. Open the repository's **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Select branch **main** and folder **/(root)**, then click **Save**.
7. Wait a few minutes. The published address will appear in the Pages settings. It will normally look like `https://YOUR-USERNAME.github.io/dr-technologies-website/`.

GitHub Pages supports free hosting for static sites on eligible public repositories under GitHub Free. You do not need to buy hosting. A custom domain is optional and domain registration may cost money.

## Contact behaviour
The email link uses `mailto:` and opens the visitor's email app. This static website does not send or store contact form submissions. No backend is included.

## Before publishing
Confirm project descriptions, project status, team contributions and any college/sponsor intellectual-property or publication permissions. The portfolio intentionally describes these as academic/research work, not client deliveries.
